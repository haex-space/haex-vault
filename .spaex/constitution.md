## SHOULD_NOT

- Avoid exposing implementation details solely to work around a local borrow or lifetime problem, and avoid re-exporting everything or creating pass-through modules that add no boundary. _[from `com.github.haexmas.atoms.coding-guideline-rust/rust`, `com.github.haexmas.atoms.general-coding/general-coding`]_
- Avoid weakening a production invariant merely to make a test convenient. _[from `com.github.haexmas.atoms.coding-guideline-rust/rust-testing`]_
- Avoid circular imports, hidden global state, and a domain layer that knows about infrastructure details. _[from `com.github.haexmas.atoms.general-coding/general-coding`]_
- Avoid letting a generic utility module become a dumping ground. _[from `com.github.haexmas.atoms.general-coding/general-coding`]_
- The agent should not consolidate duplicated arrange/assert/setup blocks across test cases, since each test's setup documents that test's own assumptions in place. _[from `com.github.haexmas.atoms.graphify-first-authoring/graphify-first-authoring`]_
- Avoid adding a new dependency when it can be avoided. _[from `com.github.haexmas.atoms.ponytail/ponytail`]_
- Avoid adding boilerplate that nobody asked for. _[from `com.github.haexmas.atoms.ponytail/ponytail`]_

## MAY

- A required or module-private test-module declaration or registration (for example a Rust `#[cfg(test)] mod tests;` item) MAY remain in the production file, provided the test bodies and test-only helpers themselves live in dedicated test files. _[from `com.github.haexmas.atoms.coding-guideline-rust/rust-testing`, `com.github.haexmas.atoms.general-coding/general-coding`]_
- Generated files, vendored code, snapshots, and other files not normally edited by hand MAY exceed the 500-line boundary, but should be excluded from the size assessment. _[from `com.github.haexmas.atoms.general-coding/general-coding`]_
- The operator may suspend this graphify-first authoring rule for the current session with any natural-language request to that effect (e.g. "skip graphify check", "don't consult the graph this session"); the agent must honor the intent, not a specific phrase. _[from `com.github.haexmas.atoms.graphify-first-authoring/graphify-first-authoring`]_
- A standing state that is not the result of the last action — a confirmation question, a denied permission with the way to allow it, an insecure-source warning, missing credentials, an entry deleted on another device, or the stored status of a background run — may stay inline, since it is not a message. _[from `com.github.haexmas.atoms.holzi/holzi-ui-feedback`]_
- An icon on a button may change to show its state, such as a copy icon turning into a check mark. _[from `com.github.haexmas.atoms.holzi/holzi-ui-feedback`]_
- Only when the outcome is visible nowhere else — such as a copy, a passed connection test, or a file written by an export — may the component show a success toast (`toast.success` from `vue-sonner`). _[from `com.github.haexmas.atoms.holzi/holzi-ui-feedback`]_
