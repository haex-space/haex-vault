# Quickstart: sync rule from the context menu

Run with a build of this branch. Each row is a check of a scenario of [spec.md](spec.md).

| #         | Do                                                                                                        | Expect                                                                                                                                                                       |
| --------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US1.1–1.3 | Right-click a folder on this device, choose "Sync-Regel erstellen …", pick a cloud folder as target, save | the dialog opens with the folder as source and no target; after saving a confirmation shows, the file browser still shows the same folder, the rule is in the sync rule list |
| US1.4     | Open the dialog from the menu, cancel                                                                     | no rule exists                                                                                                                                                               |
| US1.5     | Open the dialog from the menu, pick another source folder                                                 | the dialog uses it as in the list's dialog                                                                                                                                   |
| US2.1–2.2 | Right-click the empty area of a folder (long press on touch)                                              | the entry is offered; the dialog opens with the open folder as source                                                                                                        |
| US2.3     | Split view, use the entry in the right panel                                                              | the dialog gets the right panel's folder                                                                                                                                     |
| US3       | Right-click a file, choose the entry, pick a target folder, save                                          | the dialog shows no delete mode; the saved rule is a file rule                                                                                                               |
| US4.1     | Open the menu in holzi's own places, in a file of a received share, in a locked encrypted folder          | no entry                                                                                                                                                                     |
| US4.2     | Select several entries, open the menu                                                                     | no entry                                                                                                                                                                     |
| US4.3     | Open the menu on a folder of another own device, a cloud storage, an unlocked encrypted folder            | the entry is offered                                                                                                                                                         |
| FR-009    | Open the menu with the context menu key (Shift+F10), choose the entry by keyboard, close the dialog       | the dialog opens; afterwards the focus is back in the list                                                                                                                   |
| FR-010    | Create a rule from the sync rule list                                                                     | works as before                                                                                                                                                              |
