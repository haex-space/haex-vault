# Contract: commands, events and actions between the window and the core

Types are exported with ts-rs to `src/types/bindings/` (data-model.md, "Frontend types"). Errors are
`HolziError` codes; texts come from i18n (`chat.error.*`). Agent conversations keep their existing
commands (`send_message`, `list_threads`, …; useChat.ts).

## Events

| Event                            | Payload                                                                           | Notes                                                                                                                                            |
| -------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `vault-data-changed`             | `{ tables }`                                                                      | existing; the list and open conversations refresh on `chat_threads`, `chat_peer_messages`, `chat_members`, `chat_deliveries`, `chat_attachments` |
| `chat-transfer`                  | `{ attachmentId, direction: "up"\|"down", bytesDone, bytesTotal, state, error? }` | throttled 100 ms like files/transfer                                                                                                             |
| `chat-send-confirm-request`      | `{ requestId, agent, threadTitle, recipients[], text, attachments[] }`            | 120 s timeout → refused                                                                                                                          |
| `files-agent-permission-request` | existing, new kind `contactChats`                                                 | R16                                                                                                                                              |
| `chat-notification-open`         | `{ threadId }`                                                                    | a tap on a chat notification: open the chat at `/contact/<threadId>` (FR-023)                                                                    |
| `chat-notification-in-app`       | `{ threadId, title, body? }`                                                      | the system showed none (Android: permission refused): holzi shows it as a message                                                                |

## Window actions (`src/lib/actions/chatActions.ts`)

| Action                                              | Agent-callable        | Notes                                                                                                                                                                                                                                                          |
| --------------------------------------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `chat.conversation.new`                             | no                    | opens NewConversationDialog                                                                                                                                                                                                                                    |
| `chat.contacts.conversations.list`                  | yes, external too     | needs `contactChats` grant per conversation; denied ones are absent                                                                                                                                                                                            |
| `chat.contacts.messages.read`                       | yes, external too     | `{ threadId, before?, limit ≤ 100 }`; text, sender, time, file names                                                                                                                                                                                           |
| `chat.contacts.message.send`                        | yes, `confirmsItself` | input `{ threadId: UUID, text?, files?: PickedFile[], contacts?: ContactShareBuildArgs[], confirming_action_ids: string[] }`; result `{ messageId: UUID }`; shows exact text, attachment names and recipients before sending; no send until confirmed (FR-071) |
| `chat.peer.send`, `chat.peer.resend`                | **no** (`guardrails`) | the window's own send and "Erneut senden" (PR C2); agents send only through `chat.contacts.message.send`                                                                                                                                                       |
| `chat.group.*`, `chat.request.*`, `chat.settings.*` | **no**                | FR-072                                                                                                                                                                                                                                                         |

MCP (spec 021): data scope `chat.contacts.read` covers the two read actions; `chat.contacts.message.send`
is reachable only with that scope and still confirms itself (mcp_server/dispatch.rs).
