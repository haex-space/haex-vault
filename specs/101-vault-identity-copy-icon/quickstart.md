# Quickstart: Vault Identity Copy Icon

1. Open **Einstellungen → Föderation** for a vault with a public identity.
2. Confirm the public-key row shows a copy icon button without a visible text label.
3. Confirm the control can be reached with the keyboard and has a localized accessible name.
4. Activate it and verify the public key is copied and the button shows its check for a moment.
5. If clipboard access fails, verify the existing error toast remains available.

No backend, storage, or migration changes are involved.
